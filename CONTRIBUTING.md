# Contribution Guidelines

- One resource per pull request, added to the bottom of the relevant section.
- Format: `- [Name](link) - One neutral sentence on what it is and why it helps someone learn. 🆓` (use 💵 for paid, 🆓/💵 for free tier plus paid).
- Prefer resources that let people learn without buying hardware.
- Link directly to the resource, not to affiliate or tracking URLs.
- If you are involved with the resource, say so in the pull request.
- Check the link works and the description is accurate.
